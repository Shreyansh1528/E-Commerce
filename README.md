# ShopPilot - E-Commerce Operations Platform

A modern, high-precision operations and analytics platform for multi-channel e-commerce storefronts.

## 🚀 Live Demo on GitHub Pages
Once deployed, your application is live at:
**[https://shreyansh1528.github.io/E-Commerce/](https://shreyansh1528.github.io/E-Commerce/)**

## 🛠 Features & Screens Included
- **Overview Dashboard (`index.html`)**: Real-time sales telemetry, gross revenue, order volume, live fulfillment funnel, conversion metrics, and quick actions.
- **Orders Management (`orders.html`)**: Multi-channel order list, status tracking (Fulfilled, Unfulfilled, In Transit), batch selection, and detailed order inspector.
- **Inventory & Stock Operations (`inventory.html`)**: Warehouse management, SKU tracking, low stock alerts, stock level indicators, and restock actions.
- **Store Analytics & Intelligence (`analytics.html`)**: In-depth channel breakdown (Shopify, Amazon, TikTok Shop, Wholesale), revenue trends, and conversion rate analysis.

## ⚙️ How to Deploy on GitHub

### Method 1: Automatic GitHub Actions (Recommended)
This repository contains `.github/workflows/pages.yml`. When you push or upload the files to your `main` branch:
1. Go to your repository **Settings** -> **Pages**.
2. Under **Build and deployment** -> **Source**, choose **GitHub Actions**.
3. GitHub will automatically trigger the deployment workflow on every upload.

### Method 2: Deploy from Branch
1. Go to repository **Settings** -> **Pages**.
2. Under **Build and deployment** -> **Source**, select **Deploy from a branch**.
3. Under **Branch**, select `main` and folder `/ (root)`.
4. Click **Save**.
5. Within 1-2 minutes, your website will be live!
